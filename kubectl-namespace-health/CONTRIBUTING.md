# Contributing

Keep the simulation independent of a live cluster. Discuss behavior changes before expanding scope. Add a meaningful failing test for a bug, make the smallest fix, then run the full suite and coverage checks from README. Keep the policy, fixture schema, examples and docs consistent. Do not commit secrets, virtual environments or claims of checks that were not run. Preserve MIT notices when reusing code.

Current authorship context: prepared with AI assistance for Ayaan Jindal's OJT learning project. A student should explain and validate the code before submission. A contribution to this standalone project is distinct from an accepted upstream Kubernetes change.
